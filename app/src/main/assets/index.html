HTML ફાઇલ કે URL માંથી APK બનાવો
ખાલી રાખશો તો જાતે બની જશે. Play Store પર મૂકવી હોય તો જ લખો (નાના અંગ્રેજી અક્ષરો, સ્પેસ વગર).
હજી ફાઇલ પસંદ કરી નથી
🖼️
🔑 GitHub ટોકન (એક જ વાર નાખવાનું)
ટોકન બનાવવા માટે અહીં ક્લિક કરો (GitHub માં લોગિન કરો, repo અને workflow ટિક રહેવા દો, Generate token દબાવો, ટોકન કોપી કરીને અહીં પેસ્ટ કરો). ટોકન ફક્ત તમારા ફોનના બ્રાઉઝરમાં રહે છે અને ફક્ત github.com ને મોકલાય છે.
બિલ્ડ GitHub પર થાય છે અને Repository Public બને છે, એટલે તમારી HTML તે Repository માં બધા જોઈ શકે. ખાનગી માહિતી (પાસવર્ડ, API key) HTML માં ન રાખવી.
⬇️ APK ડાઉનલોડ કરો
